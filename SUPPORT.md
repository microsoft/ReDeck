# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/ReDeck/issues) to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates.

For new issues, file your bug or feature request as a new Issue. When reporting bugs, please include:

- Steps to reproduce the issue
- Expected vs actual behavior
- Your environment (OS, Python version, model provider)
- Relevant logs or error messages

For general questions about using ReDeck, please open a [Discussion](https://github.com/microsoft/ReDeck/discussions).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
