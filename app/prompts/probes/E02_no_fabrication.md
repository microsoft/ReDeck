# E02: No Fabrication — fabricated

## Focus
No unsupported new numbers/facts/conclusions/background details.

## Pass if
1. New material clearly supported or non-factual scaffolding
2. No invented statistics/entities/outcomes
3. Recommendations bounded by source
4. Embellishment doesn't add false certainty

## Fail if
1. Deck introduces unsupported number/fact
2. Conclusion presented as sourced when invented
3. Contextual background changes interpretation without evidence
4. Rhetorical polishing inserts unsupported specifics

## Do not flag
- Generic narrative connectors ("overall", "in practice") adding no factual content

## Confidence threshold
- Only report when CONFIDENT content is invented
- Medium confidence if content could exist in parts not in summary

## MANDATORY check
- Table/figure description verification — cross-check each "Table N: [description]" against source evidence

## No overlap with D-series
- Wrong number → D2, not E2

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If number exists in source but is wrong → D02

## Evidence requirements
- Exact added statement
- Source search showing lack of support
