# A02: Missing Context — opening_context

## Focus
Do the first 1–2 slides establish enough context for the audience to understand why this presentation matters now?

## Pass if
1. The opening explains the problem, situation, or relevance
2. The audience knows why this presentation is happening now
3. Key background information is introduced early
4. The opening frames the rest of the deck

## Fail if
1. The deck jumps into details without framing the problem or situation
2. Generic title pages waste the opening without providing context
3. Audience relevance appears much later than slides 1–2
4. Later slides depend on context that was never introduced

## Do not flag
- A concise opening that still frames the topic effectively

## Severity
- critical when the audience cannot orient themselves after the first two slides
- major when partial context is given but key framing is missing
- minor when context is present but could be stronger

## Boundary — use another probe instead
- A02 is about the OPENING (slides 1–2). If later slides lack context individually, that is still A02.
- If the overall slide-to-slide progression is disjointed → A03 (poor_flow).
- Do not report both A02 and A03 for the same problem.

## Evidence requirements
- Cite content on slides 1–2
- State whether the opening identifies stakes, audience, task, or decision need
