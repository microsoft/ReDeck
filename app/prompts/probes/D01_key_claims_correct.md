# D01: Key Claims Correct — incorrect_claim

## Focus
Key claims faithfully reflect source materials.

## Pass if
1. Major claims align with source
2. Summaries don't overstate
3. Wording preserves direction/scope
4. No central slide depends on incorrect statement

## Fail if
1. Key claim contradicts source
2. Tentative evidence → definitive claim without support
3. Scope/condition/population changed altering meaning
4. Major takeaway directionally wrong

## Do not flag
- Stylistic paraphrase preserving full meaning traceable to source

## Strict traceability
- Every claim should trace to specific source part. Flag if sounds plausible but can't be found.
- Watch for: generalizations beyond what paper demonstrates, scope shifts, numerical approximations, claims about future work not in paper

## No overlap with E-series
- If claim is wrong → D1. If absent from source → E-series.

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If claim absent from source entirely → E01/E02

## Evidence requirements
- Exact deck claim
- Corresponding source
- Specific mismatch
