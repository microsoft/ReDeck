# E03: Faithful Compression — unfaithful_compression

## Focus
Compression/paraphrase preserves original meaning.

## Pass if
1. Paraphrases preserve claim direction/scope/caveats
2. Compression removes detail without flipping message
3. Summary doesn't exaggerate certainty
4. Omitted qualifiers non-essential

## Fail if
1. Paraphrase changes meaning/certainty
2. Compression drops qualifier materially changing interpretation
3. Rewritten claim simpler but substantively inaccurate
4. Important nuance lost biasing audience

## Do not flag
- Stylistic simplification preserving same substantive claim

## Only flag when
- Compression CHANGES THE MEANING, not when it merely drops secondary detail

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If meaning is preserved but caveats omitted misleadingly → E04

## Evidence requirements
- Source wording
- Deck paraphrase
- Meaning difference
