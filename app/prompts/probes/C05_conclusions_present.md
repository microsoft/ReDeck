# C05: Conclusions Present — missing_conclusion

## Focus
Required conclusions/implications/limitations/decision statements present.

## Pass if
1. Required conclusions explicitly surfaced
2. Relevant limitations appear
3. Deck converts evidence into required implication
4. Conclusion/limitation framing matches task need

## Fail if
1. Required conclusion/recommendation entirely omitted (NO slide attempts it)
2. Major limitations absent making deck overconfident
3. Evidence presented but never converted to required implication

## Do NOT fail if
- Conclusion slide exists but is weak/generic/incomplete → that's A6

## Severity
- critical/major/minor

## Boundary — use another probe instead
- C5 only fires when content entirely absent, not when present but low quality → A6

## Evidence requirements
- Task requirement for conclusion/implication/limitation
- Where deck includes/omits
