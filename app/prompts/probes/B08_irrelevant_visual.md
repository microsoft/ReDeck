# B08: Irrelevant Visual — irrelevant_visual

## Focus
Evaluate whether images, icons, and embellishments are relevant to the slide's message.

## Core principle
Every visual element should earn its space by contributing to comprehension or appropriate tone.

## Pass if
1. Visuals reinforce the slide's subject matter
2. Stock elements don't distract from the message
3. Icons contribute meaning or aid navigation
4. Visual choices support the appropriate tone

## Fail if
1. Decorative images are arbitrary — no connection to slide content
2. Visuals create misleading associations with the topic
3. Repeated decorative elements waste valuable slide space
4. A visual could be removed with no information loss

## Do not flag
1. Modest branding or atmospheric imagery that fits the topic

## Severity
- major: visual actively misleads or significantly wastes space
- minor: visual is tangential but not harmful

## Boundary — use another probe instead
- Visual form wrong for data → B07
- Visual dominates over text inappropriately → B06

## Evidence requirements
Identify the irrelevant visual element, describe its content, and explain why it does not support the slide's message.
