# A05: Misallocated Detail — detail_allocation

## Focus
Does each slide allocate space proportionally to content importance?

## Pass if
1. The core argument gets proportionally more space than secondary points
2. Repeated points are purposeful (reinforcement, not redundancy)
3. The audience can identify the main point without searching

## Fail if
1. The same point is restated across slides without adding value
2. Verbose qualifiers push the core argument into a small corner — but faithfully quoting a source is NOT a failure

## Do not flag
- A dense slide in a technical appendix
- Slides with many bullets if each bullet carries distinct information

## Severity
- critical when the core argument is buried and a reader would miss it
- major when significant space is wasted on redundancy
- minor when detail allocation is slightly off but the main point is still findable

## Boundary — use another probe instead
- A05 = narrative detail allocation (the RIGHT content gets emphasis)
- B09 = visual density (too much content packed into one slide visually)
- Do not report both A05 and B09 for the same slide unless the issues are genuinely independent

## Evidence requirements
- Cite duplicate statements across slides
- Show where a core point is underdeveloped while secondary content is over-expanded
