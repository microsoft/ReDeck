# C02: Must-Cover Points — missing_point

## Focus
All mandatory key points from task brief represented.

## Pass if
1. Each must-cover point appears explicitly or equivalent paraphrase
2. Represented with enough substance
3. Coverage supports story
4. No important point omitted for convenience

## Fail if
1. Must-cover points absent
2. Technically mentioned but too weakly
3. Covers easier points omits harder ones
4. Coverage so compressed audience would miss

## Do not flag
- Point expressed in different language if meaning preserved
- Supplementary details from planner's auto-generated list not in original brief

## Before reporting
- Verify requested content actually exists in source materials. If not in source chunks → severity=minor, action=KEEP

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If point is present but poorly articulated → A-series probes

## Evidence requirements
- Must-cover list from brief
- Matching slide evidence or absence
