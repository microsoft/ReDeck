# E01: Traceability — untraceable

## Focus
Main content traceable to source pack.

## Pass if
1. Each important claim connected to source location
2. Evaluator can identify evidence basis
3. Unsupported synthesis limited to harmless connective phrasing
4. Traceability possible after compression

## Fail if
1. Major content can't be mapped to source
2. Key claims from model invention/unexplained synthesis
3. Multiple slides rely on opaque-origin statements
4. Source linkage so weak auditability breaks

## Do not flag
- Minor connective wording not itself factual claim

## Only flag when
- Content appears to be genuine model invention, not when could plausibly come from paper sections not in summary

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If content is traceable but wrong → D-series

## Evidence requirements
- Deck claims with/without source backing
- Source passages or absence
