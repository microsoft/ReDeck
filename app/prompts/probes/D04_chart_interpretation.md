# D04: Chart/Diagram Interpretation — chart_misinterpretation

## Focus
Chart/diagram titles, labels, captions, takeaways, structural relationships correct.

## Pass if
1. Chart titles/labels match data
2. Slide takeaway matches chart support
3. Scale/category framing correct
4. Captions don't overclaim
5. Data points match source precisely
6. Bar heights visually proportional
7. Flowchart nodes/edges correct order
8. Architecture diagram layers/components match source

## Fail if
1. Chart takeaway contradicts chart/source
2. Labels misstate measurement
3. Slide infers stronger comparison than chart supports
4. Important chart caveats omitted
5. Chart numeric values differ from source
6. Flowchart wrong order/missing critical step/invented steps
7. Architecture diagram misrepresents structural relationships

## Do not flag
- Minor stylistic caption differences
- Simplification preserving key relationships
- Reordering parallel components for visual clarity

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If chart data is fabricated → E02

## Evidence requirements
- Chart labels/data/takeaway or diagram structure
- Source evidence
- Interpretation error mechanism
