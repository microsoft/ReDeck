# D05: Causality Check — unsupported_causality

## Focus
Deck avoids unsupported comparative or causal claims.

## Boundary with E4
- D5: slide ADDS causal language stronger than source
- E4: slide OMITS caveats from source

## Pass if
1. Comparisons grounded in comparable data or qualified
2. Cause-effect language only when source supports
3. Correlations described with appropriate caution
4. Recommendations don't smuggle unsupported causality

## Fail if
1. Implies causation from correlation without support
2. Comparison ignores scope/baseline/context differences
3. Stronger language than source ("proves", "drives")
4. Turns descriptive evidence into prescriptive certainty

## Do not flag
- Clearly labeled hypothesis/interpretation explicitly framed as tentative

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If slide OMITS caveats from source → E04

## Evidence requirements
- Exact comparative/causal wording
- Source support or lack
- Needed qualification
