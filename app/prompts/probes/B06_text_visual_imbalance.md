# B06: Text-Visual Imbalance — text_visual_imbalance

## Focus
Evaluate whether the slide uses the right mix of text and visual elements to communicate effectively.

## Core principle
Each slide should use the communication mode (text, visual, or both) that best serves its content.

## Pass if
1. Visual slides explain the takeaway — not just show a picture
2. Text slides include visuals when helpful for comprehension
3. Decoration doesn't crowd out content
4. Core content is visually prominent

## Fail if
1. Source material has available figures/tables/charts that are not used when they would help
2. Visuals dominate the slide without aiding understanding
3. Decorative imagery displaces meaningful content
4. Communication mode is mismatched to the content type
5. Secondary element is louder/more prominent than the core message

## Boundary
- Only flag missing visuals when the source material actually contains relevant figures, tables, or charts that could be used

## Do not flag
1. Text-heavy policy or regulation slides
2. Methodology/background slides without meaningful visuals available
3. Metric cards, colored shapes, or accent elements counting as visual elements
4. Text-heavy academic source material (higher text-to-visual ratio is natural)
5. Uniform styling for co-equal points
6. Academic papers — higher text-to-visual ratio is expected
7. Text with visual organization (metric cards, tables, accent elements)

## Severity
- major: significant missed opportunity to use available visuals, or visuals completely dominate with no substance
- minor: slight imbalance but message still communicates

## Boundary — use another probe instead
- Density/crowding → B09
- Wrong chart type → B07
- Missing data visualization for numeric content → B10

## Evidence requirements
Describe what the slide shows, what the source material contains, and why the current text-visual balance is problematic. If flagging missing visuals, cite the specific figures/tables available in the source.
