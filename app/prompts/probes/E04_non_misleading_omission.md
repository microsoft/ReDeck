# E04: Non-Misleading Omission — misleading_omission

## Focus
Omissions don't distort source's stance/caveats/tradeoffs/priorities.

## Pass if
1. Removed details genuinely secondary
2. Omitted caveats don't change takeaway
3. Retained content represents source priorities fairly
4. Compression doesn't systematically bias

## Fail if
1. Omitted caveats/limits/exceptions materially change meaning
2. Selectively keeps favorable evidence drops balancing
3. Omission changes priority ordering misleadingly
4. Audience would reach different conclusion if omitted material restored

## Do not flag
- Omission of tangential source detail not affecting main interpretation

## Only flag when
- Omission would cause audience to reach WRONG conclusion

## Boundary with D5
- E4: slide OMITS caveats from source
- D5: slide ADDS causal language stronger than source

## Severity
- critical/major/minor

## Boundary — use another probe instead
- If slide adds unsupported causal language → D05

## Evidence requirements
- Omitted source content
- Visible deck framing
- How omission changes interpretation
