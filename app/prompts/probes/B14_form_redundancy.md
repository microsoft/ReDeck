# B14: Form Redundancy — form_redundancy

## Focus
Evaluate whether the same information is presented in multiple redundant forms on the same slide.

## Core principle
Each piece of information should be presented once in its most effective form — text and visuals should complement, not duplicate.

## Pass if
1. Each piece of information is presented once
2. Text and visuals complement each other (text explains what visual shows)

## Fail if
1. Same data shown in a chart AND in bullet text restating the chart's values
2. Numbered list repeats a diagram's steps one-by-one
3. Metric card and adjacent text both state the same number

## Severity
- major: large portion of slide is duplicated content
- minor: small duplication that slightly wastes space

## Boundary — use another probe instead
- Chart type wrong for data → B07
- Diagram merely restates text with no structural value → B07

## Evidence requirements
Identify both representations of the duplicated information, describe what is repeated, and note how much slide space the redundancy consumes.
