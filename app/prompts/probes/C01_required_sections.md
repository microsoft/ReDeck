# C01: Required Sections Present — missing_section

## Focus
All explicitly required sections present in recognizable form.

## Pass if
1. Every required section present substantively
2. Mandatory components present even if wording differs
3. No required component silently dropped

## Fail if
1. Required section missing entirely
2. Only token heading without content
3. Multiple required components merged causing one to disappear
4. Substitutes easier section

## Do not flag
- Different naming if content clearly covered

## Severity
- critical: required thematic area has ZERO representation anywhere
- major: partially covered but missing key substance
- minor: coverage exists but thin

## Proportionality
- Max TWO C1 issues per deck
- Check thematic coverage not 1:1 section-to-slide mapping
- Merging sections into one slide is expected

## Boundary — use another probe instead
- If section exists but quality is poor → A-series probes

## Evidence requirements
- Requirement source in brief
- Where present/absent in deck
