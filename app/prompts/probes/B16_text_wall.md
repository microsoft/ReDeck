# B16: Text Wall — text_wall

## Focus
Evaluate whether bullet lists and text content are organized for quick scanning rather than presenting a flat wall of text.

## Core principle
Audiences scan, not read — bullets need structure (grouping, labels, visuals) to be quickly parseable.

## Pass if
1. ≤4 bullets on the slide
2. OR >4 bullets with grouping or sub-headers
3. OR ≤6 bullets with bold lead labels
4. OR ≤6 bullets alongside a visual element (≥30% slide width)

## Fail if
1. ≥7 equal-weight bullets with no grouping, labels, or visual relief
2. Bullet lengths vary wildly (1 line vs 4+ lines) with no grouping structure

## IMPORTANT
- Bold lead labels ALWAYS count as grouping — do not flag lists with bold lead labels

## Do not flag
1. ≤4 short bullets
2. Flat enumeration where grouping genuinely doesn't apply
3. ≤6 bullets with bold lead labels
4. ≤6 bullets alongside a table or chart

## Severity
- major: ≥7 ungrouped bullets with no labels
- minor: 5–6 ungrouped bullets with no labels and no visual element

## Boundary — use another probe instead
- Content too dense overall → B09
- Layout wrong for content → B02

## Evidence requirements
Count the bullets, note whether they have grouping, sub-headers, or bold lead labels, and describe the visual structure (or lack thereof).
