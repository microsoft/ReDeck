---
name: redeck-style-patterns
description: Configure the current ReDeck typed design library without injecting a second style authority.
---

Use `redeck codegen --help` for `--palette`, `--lum`, `--design-family`, `--style-archetype`,
`--information-density` and `--asset-mode`. Theme owns colors; a design family owns non-color
materials. The Slide Design Program is the single generation authority. Do not load historical
full-page templates or manually inject the old pattern CSS alongside it.

For generation and repair, read [the maintained workflow](../redeck/SKILL.md).
