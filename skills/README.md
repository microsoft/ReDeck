# ReDeck Agent Instructions

The maintained skill is [redeck/SKILL.md](redeck/SKILL.md). It delegates execution to the
installed current CLI rather than embedding a second renderer, style system or repair engine.
Legacy Markdown filenames remain short compatibility references.

Install the repository first (`python -m pip install -e .`, then `python -m playwright install chromium`).
The skill requires access to that CLI and to authorized local source material.
